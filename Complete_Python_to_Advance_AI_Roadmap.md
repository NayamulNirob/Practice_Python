## ⚡ Practical Milestones

1. **Phase 1 Milestone**: Finish the Python beginner course and write 1 small CLI script or web scraper.
2. **Phase 2 Milestone**: Complete an exploratory data analysis (EDA) on a dataset with Pandas and Matplotlib.
3. **Phase 3 Milestone**: Train and evaluate a gradient boosted model (XGBoost) with Scikit-Learn.
4. **Phase 4 & 5 Milestone**: Follow Karpathy's "Let's build GPT" tutorial to build and train your own mini language model in PyTorch.
