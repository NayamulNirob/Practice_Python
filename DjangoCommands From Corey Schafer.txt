Django Install : python -m pip install Django

Django version check: python -m django --version

Django clone to local: git clone https://github.com/django/django.git 

Install Django: py -m pip install -e django\ 

To check the admin : django-admin

Create a project via terminal: django-admin startproject appname projectname

Strat the server: py manage.py runserver

Django version check: py -m django --version

Create polls: py manage.py startapp appname

create make makemigrations or db table: py manage.py makemigrations

create maigration: py manage.py migrate

create a superuser via admin: py manage.py createsuperuser

create a table in DB: py manage.py sqlmigrate blog 0001 # last two is app name and migration Number.


pycharme config of Environment variables: PYTHONUNBUFFERED=1;DJANGO_SETTINGS_MODULE=mysite.settings

Create a app: python manage.py startapp appname

shell start : py manage.py shell
